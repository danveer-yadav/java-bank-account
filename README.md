## Java Bank Account

A beginner Java OOP project built to practice encapsulation and constructors.

## Features

- Initialize a bank account
- Deposit money with validation
- Withdraw money with balance validation
- Access balance using a getter

## Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Access Modifiers
- Methods and If-Else

## Language
   Java

Created as part of my Java learning journey.
